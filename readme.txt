CleanGutters Landing Page — Deploy Instructions
================================================

Option 1: Netlify Drop (fastest, free)
  1. Go to https://app.netlify.com/drop
  2. Drag the folder "cleangutters-landing" (as a .zip) onto the page
  3. Done — you'll get a public URL instantly

Option 2: Netlify CLI
  npx netlify-cli deploy --prod --dir=.

Option 3: Any static host (Vercel, GitHub Pages, etc.)
  Just upload all files — index.html + _next/ directory

GA4 Tag: G-E7NG44429T is embedded (in <head>, alongside AW-18146670851 for Google Ads conversion tracking). Both configured via gtag.js loaded after LCP via requestIdleCallback.
Note: G-NDC5JLN0MJ was from a different (Next.js) project — not for this site.
